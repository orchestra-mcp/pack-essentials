# orchestra-mcp/pack-essentials

Core project management skills and agents for any Orchestra project

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-essentials
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-essentials")
```
